A spot-the-difference game in three hand-drawn procedural scenes: Pasar Senja (7 differences), Pelabuhan Pagi (10), and Hutan Kunang-kunang (12). Two near-identical pictures side by side, click the differences before the timer runs out — hints, score, and sound included. All art is drawn in code; no external assets, no network.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome.
